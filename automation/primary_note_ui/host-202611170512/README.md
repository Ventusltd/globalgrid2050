# ROOT primary-note renderer for V9.33

Uses the existing row buttons, dialog, disclosures and styles. It distinguishes
refusal, grant and grant with modifications, and PDF letters from public
government HTML. Government capacity descriptions retain their own source link.
Whole-development scope, separate battery identities, unknown MW/MWh, frozen
operators and different legal applicants remain explicit. It preserves the
original Botley note presentation and does not alter headline associations.

This renderer belongs to ROOT, separately from producer PR151. Its exact bytes,
SHA-256 and Git blob are pinned in the candidate's existing v1 cartridge manifest.
The immutable V9.32 renderer and source cache are retained.

Publication precision follows the reviewed data: DAY shows a date only;
RECORDED_METADATA_TIMESTAMP retains the recorded clock with an explicit metadata
qualification. Neither representation supplies a new decision timestamp.
