# Code map, ten views

A read-only web page with ten views of the same live data: every named block of GlobalGrid2050 code, its function families, their numbered lines, and the dependencies between them. Open `index.html` to choose a view.

- Derived from: `testcode/202609141522/` (the ten-view code map, generation 2). Behaviour and layout are unchanged; view folders were given plain names and the on-screen wording was rewritten in plain engineering language.
- Wording: every data-derived string passes through `../corporate.js` (via `say()`, `sayType()` and `pageLink()` in `core.js`).
- Data: `https://ventusltd.github.io/stars/` (`blocks/`, `code/`) and `raw.githubusercontent.com`, read live when the page opens.
- Not included: the internal build notes of the origin folder.
