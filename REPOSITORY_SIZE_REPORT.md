# GlobalGrid2050 Repository Size Report

This report is generated by `scripts/track_repository_size.py`.

It can be updated manually through the `Track Repository Size` workflow, or automatically once per month.

## Purpose

Track repository growth and provide a clear planning signal for future data repository expansion.

## Current known baseline

GitHub recently reported this repository at approximately `81,652 KB`, about `79.74 MB`.

This is well below the practical planning threshold of `500 MB` and the later action threshold of around `1,000 MB`.

## Future expansion options

1. Keep this repository as the website and application repository.
2. Consider a future `globalgrid2050-data` repository when size or workflow performance justifies it.
3. Test any future data path changes before relying on them in live applications.
4. Keep repository size monitoring informational during launch preparation.
