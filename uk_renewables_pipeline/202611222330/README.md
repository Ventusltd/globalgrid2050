# V9.73 — REPD capacity intelligence reports

Immutable successor of V9.72 (202611222222), introducing three additive dashboard actions: **Operator MW**, **Status MW** and **Region MW**. Defaults are all official qualifying REPD records and all source statuses. Optional Current Table Filters uses the existing live filtered REPD spine.

Each group displays original REPD names/statuses, project count, combined recorded MW/MWp and separate solar MWp/other MW totals. Expand any group for full status breakdown and paginated project drill-down (100 at a time). Project links return to existing PipelineNews MAP/A4 and direct MAP links use the identical canonical receiver as the native REPD table; no new map contract is introduced. CSV export is available per report.

No new data, collector, Chart.js dependency, geographic inference, company-family rollup, interconnector mixing, Journey UI, GridAtlas change or historical release edit. All existing V9.72 content except index/README/CHANGES is inherited unchanged. Test every status including non-current/refused/withdrawn, null values, unique project identities, all 7,775 source rows and multi-browser operations before publication.
