Module & table

Placement changes keep electrical order. Opposed faces use five-high patches, tilt magnitude and a 0.15 m horizontal face gap; patch spacing is 1 m. Edit faceGapM / patchGapM in the recipe. Individual XYZ placements override a preset. No collision or structural check is implied.

8° is an editable demonstration assumption. Azimuth rotates the table around world +Z; 0° means the module-row axis is +X.

Electrical path

Box outlets at 35% / 65% width and mid-length, lead polarity/lengths, height, tilt and clip routing are editable assumptions. Selecting a module imports its outline dimensions only.

Programmable recipe · order / placement / routes

Edit each string's own order with “custom”, or set XYZ interior waypoints by link key, e.g. “S01-M01+>S01-M02-”. Move any module independently with modulePlacements: {"S01-M01":{"originXYZ":[4,3,2],"tilt":8,"azimuth":45,"rotation":90}}. Angles are degrees; rotation acts in the module plane. Endpoints stay attached to boxes. Physical moves never change string membership. Cross-string connections are refused.
