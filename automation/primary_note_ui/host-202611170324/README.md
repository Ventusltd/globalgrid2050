# ROOT primary-note renderer

This small renderer extends the existing Machine Read Notes dialog and row buttons. It consumes the separately byte-pinned, reviewed provisional model; it is not an acquisition, identity or licence gate. The local edition manifest pins this file by SHA-256, Git blob and byte count. It creates no new principal panel and does not change headline matching or the frozen register.

Sources, document/event/retrieval clocks, original REPD status and dates, original-capacity qualifications, unknown later status and narrow OGL attribution remain visible. All content uses text nodes and validated source links.
