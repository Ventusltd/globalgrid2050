# V9.3 — Proven V5/V7.1 interface restoration

Date: 23 August 2026

## Reason for release

V9.2 correctly removed V8's four-gauge and oversized-table overrides, retained the complete 7,680-record canonical universe and integrated V9 features into an eight-column table. It did not, however, load the bounded V7.1 mobile correction that had already been production-proven at 390, 430, 440 and 768 px.

The first V9.3 candidate restored that proven mobile file. A subsequent deterministic layout replay found one additional bounded defect: because V9.3's status label is longer than V7.1's, the status extended beyond the header between 769 and approximately 918 px while desktop overflow remained hidden. The final V9.3 candidate therefore stacks only the header from 769 through 920 px. Gauges remain three-column, the table remains V5-style and all V9 functions remain unchanged.

V9.3 advances the visible version so V9.2 remains recoverable evidence.
