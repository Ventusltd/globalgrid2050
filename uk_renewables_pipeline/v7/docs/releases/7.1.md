# V7.1 — Modular V5 parity

V7.1 is one approved feature: convert the live V7.0/V5 monolith into bounded modules without changing its data or decisions.

## Delivered

- Thin HTML shell and exact extracted V5 stylesheet.
- Shared state and utility modules.
- Independent gauges, newspaper and projects plugins.
- Versioned plugin contract and manifest with declared DOM ownership.
- Machine-readable North Star contract with preflight and postflight validation.
- Dataset, interface, module and ES-module syntax parity checks.
- Optional browser smoke harness for desktop, mobile, filters, CSV and independent source failure.
- One local validation command and one read-only GitHub Actions launcher calling that command.

## Deliberately unchanged

- `dist/repd_master.json`: 10,784 legacy GeoJSON features; 5,210 displayed records at the inherited 1 MW floor.
- `dist/major_project_news_v5.json`: 125 stories, 559 eligible projects and a 366-day horizon.
- Project/news source selection, search, filters, gauges, table, Google News links and CSV semantics.
- The inherited first-name-match NEWS SIGNAL, including its known limitations and `not REPD-confirmed` label.
- V1–V6 files and all frozen data assets.
