# V9.6 — Mobile cards and official-capacity ranges

V9.6 freezes V9.5.1 and creates a separate application.

The project filter accepts optional inclusive minimum and maximum MW values and evaluates only canonical `capacity_mw`. Empty fields are unbounded. Invalid or reversed ranges fail visibly and return no results until corrected.

On mobile, all canonical records remain loaded but only 50 matching project cards are inserted into the DOM initially. `LOAD 50 MORE` reveals the next batch. Search, filters, gauges and CSV continue to operate on the complete matching set. Headlines use the same rule with batches of 20 while retaining all 133 `ALL` and 45 `RELEVANT` stories.

The mobile card layout removes the inherited 1,280 px internal table width, exposes official identity and update date beneath the site name, preserves expandable project records and provides 44 px actions. Desktop presentation remains the V9.5.1 shell.
