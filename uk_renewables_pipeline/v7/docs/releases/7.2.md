# V7.2 — Canonical UK project spine

This data-only release creates the canonical utility-scale project foundation without changing the live V7.1 interface or inherited newspaper.

## Validated output

- 766 REPD-bound records across 718 developments.
- 384 solar projects strictly above 49 MWp, totalling 34,073.49 MWp.
- 382 BESS projects strictly above 99 MW, totalling 106,338.18 MW.
- No wind and no unknown-capacity qualification.
- 766 canonical WGS84 point geometries generated from official REPD British National Grid coordinates.
- Lifecycle fields, planning references, typed relationships, REPD IDs and GlobalGrid project/development IDs retained.

The 14,657-record coordinate workbook reconciles exactly to the V6 identity spine by Ref ID, technology and capacity; site names reconcile after documented missing-value and Excel `_x000D_` normalisation. Thirty-six source records lack coordinates, but none belongs to the 766-project V7.2 universe.

Geometry uses a documented OSGB36-to-WGS84 Helmert approximation. It is market-map context, never proof of a grid connection or cadastral boundary.

Status: validated data assets only. The live page remains V7.1 until a separately approved interface integration pass.
