# V9.2 — V5 interface restoration with V9 canonical features

Date: 23 August 2026

## Reason for release

V9.1 corrected V9.0's narrowed data universe, but later CSS and table overrides still changed the proven V1–V5 interaction contract. The V5 core stylesheet was present, yet `mobile.css` forced a different mobile header, `v8.css` introduced a two-column intermediate gauge layout, and the 13-column table imposed a new 1,850 px minimum width. Those changes made the dashboard feel unlike the established product even though the canonical data and V9 features were valuable.

V9.2 treats V9.1 as a frozen checkpoint and restores the latest working V5 shell without discarding V9 functionality.

## Changes

1. Load the V5-derived core stylesheet without the later mobile and V8 layout overrides.
2. Preserve exactly three gauges and the legacy 768 px mobile breakpoint.
3. Restore an eight-column project table and remove the forced 1,850 px width.
4. Keep REPD Ref, GlobalGrid ID and official update date visible beneath each project name.
5. Keep planning, lifecycle, relationship and geometry information in expandable row details.
6. Keep exact Atlas, news and filtered CSV functions; show `NO MAP` for the 28 legitimate records without geometry.
7. Load all 7,680 qualifying records by default. Filters remain optional controls over the full universe.
8. Add normalised multi-token search, a results summary, clear filters, shareable filter state and copy-ID interaction.
9. Add deterministic headline relevance scoring while retaining explicit `legacy/unverified` labelling.
10. Preserve all prior releases and integrity markers; no earlier dashboard file is modified.
