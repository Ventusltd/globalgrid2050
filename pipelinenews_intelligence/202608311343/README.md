# Pipeline News — project intelligence

Generation `202608311343`. Built from `202608300309-pipelinenews`, which is unchanged.

Additive: the panel renders inside its own host. No existing section of the
dashboard is modified and no stylesheet changes.

Open the page, then click **OPEN PROJECT INTELLIGENCE**. Five tabs over 3,054
live solar and battery projects: the window between consent and construction,
grid and data-centre proximity, and company name-match reach. The data file is
fetched once, on the first tab you open.

Built from the DESNZ Renewable Energy Planning Database Q2 2026 under the Open
Government Licence v3.0, transmission network layers, and OpenStreetMap data
under ODbL-1.0 (c) OpenStreetMap contributors. Windows and distances are
calculated from published register dates and mapped locations. Register
statuses are attributed to the register that publishes them.
