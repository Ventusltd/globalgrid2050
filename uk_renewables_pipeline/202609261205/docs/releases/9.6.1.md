# V9.6.1 — Mobile project-table repair

V9.6.1 starts from frozen V9.5.1 and changes only the mobile projects viewport.
At 768 px and below, the existing eleven-column table remains a native table,
all project columns remain available and `.tablewrap` provides horizontal touch
scrolling. The inherited 1,280 px table minimum remains unchanged.

V9.6 is discontinued. Its capacity-range controls, replacement project modules,
mobile cards and forced 1,850 px table width are not inherited.

V9.5.1 data, scripts, fixtures, newspaper, filters, search, sorting, CSV, Atlas
links and desktop layout remain byte-identical. The release retains 7,680
projects, 133 `ALL` headlines, 45 `RELEVANT` headlines and Beacon Fen's exact
Low Carbon solar binding to REPD `13599`; related BESS REPD `13600` remains
without an inherited news signal.
