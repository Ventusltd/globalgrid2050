# Workflows and release discipline

V7 should have one orchestrated writer. Collection and validation run read-only; publication promotes one content-addressed edition only after source, identity, event, referential-integrity and frontend gates pass.

Failures update private or diagnostic health output while the public manifest continues to point to the last validated edition. A newly discovered REPD quarter is staged and diffed rather than accepted through hard-coded counts or silently skipped.

V4–V6 schedules must not compete with V7 publication. Disabling or changing historical workflows requires a separate approved brick.
