# Official data and identity

V7 inherits V6's strongest principle: DESNZ remains the authority while the public browser reads a validated same-origin edition.

CSV and XLSX must reconcile by populated unique REPD Ref IDs. Missing values remain null. Official capacity and lifecycle fields are never replaced by article claims. A GlobalGrid project ID maps one-to-one to a REPD record; a development ID may relate multiple records only through explicit references or planning-reference evidence.

Coordinates are a derivative of the same canonical record spine. Missing or invalid geometry cannot delete the official record.
