# C&I solar and EV charging

REPD capacity is not a sufficient C&I classifier, and REPD does not provide a comprehensive EV-charging project class.

The C&I lane requires physical-site evidence such as rooftop or behind-the-meter context, organisation, address, planning reference or named facility. The EV lane requires separately defined charger, depot, fleet, forecourt or charging-hub sources.

These projects receive their own evidence-backed GlobalGrid identity namespace. V7 must never invent an REPD Ref for them.
