# V9.3 — Proven V5/V7.1 interface restoration

Date: 23 August 2026

## Reason for release

V9.2 correctly removed V8's four-gauge and oversized-table overrides, retained the complete 7,680-record canonical universe and integrated V9 features into an eight-column table. It did not, however, load the bounded V7.1 mobile correction that had already been production-proven at 390, 430, 440 and 768 px.

V9.3 fixes only that regression and advances the visible version so V9.2 remains recoverable evidence.
