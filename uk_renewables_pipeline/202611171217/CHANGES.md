# V9.35 - Operational date

Adds the official Operational milestone after Planning Application Submitted, with ascending/descending sorting, independent source-year selection, missing-date filtering, URL restoration and mobile Project Record access. All three date filters combine; Clear resets them. The original 50-column CSV and all canonical data remain unchanged.

Operational is the historical source milestone, not independent proof of current commissioning, operation or capacity. Unknown dates stay unknown; dates and official statuses are preserved separately, including dated non-operational statuses. Non-REPD interconnectors show not a REPD record. The existing expanded analytics uses the same controls and live nodes.
