The Spider universe: every function family and numbered line of the estate's unique code, charted through its blocks. Ten versions of one idea, each a read-only view on the same live data (the counts on each page are read from the data at open time; 209 named blocks, 10,912 families and 249,347 numbered lines at 15:25 UTC on 14 September 2026). Each opens on its own; the code is fetched from GitHub at its pinned commit when you open a family. Built 2026-09-14 UTC.
