# Pipeline News V9.60 — independent landscape REPD dashboard

Immutable successor to V9.59. An independently accessible 34px REPD maximise control opens the actual REPD register (analytics gauges, tabs, filters and existing horizontally scrollable table) as a fixed browser-viewport dashboard only in landscape. Portrait requests present a rotate message without forcing device orientation. Rotation back restores inline layout. News V9.59 functionality, source data, GridAtlas and all other modules remain unchanged.
