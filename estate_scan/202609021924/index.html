Method. Git figures come from git log --numstat against origin/main, fetched at scan time into throwaway clones — no working tree was touched and nothing was pushed. CI figures come from the GitHub Actions REST API, unauthenticated, which returns the most recent 100 runs per repository; runs is the repository's lifetime total, ok/fail describe the sampled window only. Run logs need authentication, so failures were reproduced locally rather than read.

    
Reading the columns. 2d is today plus yesterday. act is distinct days with a commit in the last 30. del/add are omitted from the index: both estates commit generated products, so line counts measure data, not work.

    
Not measured. Test coverage, review latency, runtime performance. Colour never carries meaning alone here — every state is also a word.
