# Minute-scale science display contract

Original20Hz browser display loop, with1Hz reduced-motion mode, pause controls and hidden-tab suspension. All visible rate bars reset over a60-second UTC minute; quantities are rate times elapsed seconds. UI refresh cadence is not data collection cadence or measurement precision. The electrical step model instead spans five time constants over a10-second animation and labels simulated time.

EIA and NASA ice baselines are pinned to sibling immutable source manifests. Their per-second rates are reused from independently tested models. Each fails independently. The EIA2024 baseline uses366days; NASA long-term means use365.2425days as stated in its manifest. Counters are historical rate illustrations, not measured current totals.

New cartridges are separate siblings: solar radiation2155, RC/RL2156,75TW scenario2157, MIT pipes graphic2158, nanosecond unit clock2159. No Worldometer code/feed. Static review completion and long-calendar values have no artificially animated progress. Model tests run in open-energy-cartridge.yml. Chrome evidence checks20Hz-class display ticks, pause/resume, both parameter inputs, desktop/mobile layouts and numerical invariants.

No data collector schedules are activated. All runtime data is a tiny same-origin pinned manifest. External links are attribution, not required to animate. Source licenses and selected periods live with each adapter. Future Ember/UN/forest/reserve adapters remain pending their own accepted baselines.
