# CfD and finance

Official REPD CfD fields are baseline project facts where supplied. A future adapter should reconcile official allocation and contract publications before creating CfD events.

Financial close, debt, equity, acquisition and EPC announcements remain external events with source, publication date, evidence phrase and separately reported capacity. They do not overwrite REPD status, capacity or dates.

The exact official sources and update cadence must be approved before this plugin is enabled.
