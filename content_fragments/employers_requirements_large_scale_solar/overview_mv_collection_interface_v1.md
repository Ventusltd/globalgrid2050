## Medium Voltage Collection Interface

The medium voltage collection interface is treated as the point where inverter transformers, 33kV collection feeders, RMUs, protection, earthing, harmonic behaviour, reactive power control, PPC behaviour and substation interfaces converge. This guidance requires the MV interface to be proven through single line diagrams, cable calculations, protection studies, earthing evidence, harmonic assessment, switching studies, commissioning records and as built documentation.
