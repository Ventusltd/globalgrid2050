Proving the picture, not the data. The surface below is the real page, loaded in a frame; these checks read its canvas rather than a copy of its drawing code — a proof that reimplements the thing it checks proves only that two implementations agree. No golden image is stored: because position is a pure function of the key, the expected picture is computable, so the check and the thing checked derive from the same formula.
