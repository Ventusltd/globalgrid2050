# V9.6 — V1-style mobile table and official-capacity ranges

V9.6 freezes V9.5.1 and creates a separate application.

The project filter accepts optional inclusive minimum and maximum MW values and evaluates only canonical `capacity_mw`. Empty fields are unbounded. Invalid or reversed ranges fail visibly and return no results until corrected.

Mobile keeps the established V1/V8/V9 presentation. Gauges, newspaper, controls, type and density retain the inherited layout. The projects section remains the complete 11-column desktop table inside a touch-enabled horizontal scroll container; rows are not converted into cards and columns are not removed. All 7,680 matching records and all 133 headlines are rendered as before.
